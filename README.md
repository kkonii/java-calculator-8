# java-calculator-precourse

### 기능 목록

- [x] 문자열을 입력받는다
- [x] 커스텀 구분자 형식에 따라 입력된 값을 자른다

1. #### 지정되어 있지 않을 경우(일반)
    - [x] 기본 외의 구분자가 존재하면 예외를 던진다

2. #### 지정되어 있을 경우(커스텀)
    - [x] 커스텀 구분자가 단어(1글자)가 아니면 예외를 던진다
    - [x] 문자열 내 지정되지 않은 구분자가 존재하면 예외를 던진다

3. #### 그 외의 형식으로 입력될 경우
    - [x] 예외를 던진다

- [x] 구분자를 기준으로 문자열을 잘라 숫자들을 추출해낸다
- [x] 숫자가 양수가 아닐 경우, 예외를 던진다
    - [x] 0 혹은 음수
    - [x] 단어 혹은 문자열
- [x] 추출된 숫자들의 합을 구한다
- [x] 합을 콘솔에 출력한다

<br>

### 해결할 버그

- [x] 5-6-6 으로 입력하면 기본 구분자로 분류됨
- [x] //.\nh.h.h.g 를 입력하면 예외 처리가 안 됨
- [x] 0 을 넣으면 검증에 잡히지 않음
