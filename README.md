# java-calculator-precourse

### 기능 목록

- [x] 문자열을 입력받는다
- [x] 입력된 값의 패턴을 확인한다

1. #### 기본 패턴일 경우
    - [x] 다음 단계로 넘어감

2. #### 커스텀 패턴일 경우
    - [x] 커스텀 구분자가 단어(1글자)가 아니면 예외를 던진다
    - [ ] 기본 구분자를 커스텀에 넣을 경우, 예외를 던진다
    - [ ] 숫자를 커스텀 구분자로 사용할 경우, 예외를 던진다
    - [x] 문자열 내 지정되지 않은 구분자가 존재하면 예외를 던진다

3. #### 그 외의 형식으로 입력될 경우
    - [x] 예외를 던진다

- [x] 구분자를 기준으로 문자열을 잘라 숫자들을 추출해낸다
- [x] 숫자가 양수가 아닐 경우, 예외를 던진다
    - [x] 0 혹은 음수
    - [x] 단어 혹은 문자열
- [x] 추출된 숫자들의 합을 구한다
- [x] 합을 콘솔에 출력한다

<br>

### 해결할 버그

| 입력값          | 버그 내용                            | 해결 |
|--------------|----------------------------------|----|
| 5-6-6        | 기본 구분자로 분류됨                      | 완료 |
| //.\nh.h.h.g | 예외 처리가 안 됨                       | 완료 |
| 0,0:9        | 검증에 잡히지 않음                       | 완료 |
| //\\\n5\5\5  | `PatternSyntaxException` 예외가 발생됨 | 완료 |
| //.\n5\|5    | 케이스에 알맞지 않은 예외 문구가 실행됨           | 완료 |
