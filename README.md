# java-calculator-precourse

### 기능 목록

- [ ] 문자열을 입력받는다
- [ ] 커스텀 구분자가 지정되어 있는지 확인한다

1. #### 지정되어 있지 않을 경우(일반)
    - [ ] 기본 외의 구분자가 존재하면 예외를 던진다

2. #### 지정되어 있을 경우(커스텀)
    - [ ] 문자열 내 지정되지 않은 구분자가 존재하면 예외를 던진다

- [ ] 구분자를 기준으로 문자열을 잘라 숫자들을 추출해낸다
- [ ] 숫자가 양수가 아닐 경우, 예외를 던진다
- [ ] 추출된 숫자들의 합을 구한다
- [ ] 합을 콘솔에 출력한다
